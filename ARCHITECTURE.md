# Architecture finale v4

## Public
Accueil → filtres → fiche cours → source/licence → téléchargement si autorisé.

## Collecte
Recherche → ouverture de la page → détection de licence → classification niveau/matière
→ déduplication → téléchargement PDF uniquement si licence compatible → validation admin.

## Licences
- CC BY / CC BY-SA / CC0 / domaine public : téléchargement local possible après contrôle.
- CC BY-NC / CC BY-NC-SA : lien/indexation et validation; pas de copie automatique par défaut.
- CC BY-ND : ne pas modifier; copie seulement après vérification des conditions.
- Licence inconnue : aucune republication.

## Données conservées
Titre, niveau, matière, chapitre, auteur, licence, source, fichier, statut, date.

## Exploitation
Le site peut rester entièrement gratuit. Les licences NonCommercial doivent être respectées
si une monétisation est ajoutée plus tard.
