# Mise en ligne

1. Copier `.env.example` vers `.env`.
2. Mettre une vraie SECRET_KEY et un mot de passe administrateur fort.
3. Installer les dépendances avec `pip install -r requirements.txt`.
4. Tester avec `python app.py`.
5. En production : HTTPS + serveur WSGI + sauvegardes.
6. Sauvegarder `data/courses.db` et `data/courses/`.
7. Vérifier la licence avant publication.
8. Ne pas monétiser une ressource CC BY-NC sans vérifier que l'usage est autorisé.
